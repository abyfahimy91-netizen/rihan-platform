# مرجع ماژول‌های ریهان (Module Registry)

> **وضعیت:** تأییدشده (D-051)
> **هدف:** ایجاد تنها مرجع حقیقت برای شناسه‌های ماژول‌ها.
> **قانون طلایی:** هر ارجاع به ماژول، فقط از طریق این سند معتبر است.

---

## چرا این سند لازم است؟

در USER-STORIES.md شماره‌گذاری ماژول‌ها با MVP-SCOPE.md متفاوت بود. این ناسازگاری باعث مشکل در:
- ردیابی (Traceability) داستان‌های کاربر به ماژول‌ها
- نوشتن ADRها در فاز ۴
- تست‌نویسی در فاز ۵
- یکپارچگی اسناد

---

## قوانین استفاده

### ۱. مرجع نهایی
این سند تنها مرجع معتبر برای شناسه‌های ماژول است.

### ۲. فرمت استاندارد
همیشه از فرمت M + عدد استفاده کنید:
- درست: M1, M2, M14
- غلط: MOD-001, M01, Module-1

### ۳. ارجاع در اسناد
هر فایل جدید باید قبل از ارجاع به ماژول، این سند را بخواند.

### ۴. ممنوعیت
هیچ فایل جدیدی حق استفاده از شماره‌گذاری محلی یا متفاوت را ندارد.
