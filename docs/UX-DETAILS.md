## ۱. صفحه اصلی (Homepage)

### ۱.۱ ساختار

بر اساس تحقیق Luigi's Box و NN/g:

- Header
- Hero Banner (داستان ریهان)
- Trust Bar (۴ ستون اعتماد)
- دسته‌بندی‌های اصلی
- محصولات منتخب / پرفروش
- داستان ریهان (کوتاه)
- آخرین محصولات
- Footer

### ۱.۲ Hero Banner

**محتوا:**
- تصویر: عکس حرفه‌ای از محصولات ریهان
- عنوان اصلی: "فروشگاه آنلاین اعتمادمحور"
- زیرعنوان: "خشکبار هوراند، لباس، لوازم منزل - هر محصول با داستان واقعی"
- CTA اصلی: "مشاهده محصولات"
- CTA ثانویه: "داستان ما"

**قوانین:**
- ارتفاع: ۶۰۰px دسکتاپ، ۴۰۰px موبایل
- لود: eager (نه lazy)
- فرمت: WebP با fallback
- Responsive: ۳ breakpoint

### ۱.۳ Trust Bar

**۴ ستون اعتماد** (بر اساس تحقیق Trustmary):

| ستون | آیکون | متن |
|------|-------|------|
| راستی‌آزمایی | ✓ | هر محصول تست شده توسط خانواده |
| شفافیت | 👁️ | قیمت شامل ارسال، بدون هزینه پنهان |
| اعتماد | 🛡️ | ۳۰ روز ضمانت بازگشت |
| داستان | 📖 | هر محصول یک داستان واقعی |

### ۱.۴ دسته‌بندی‌ها

- حداکثر ۶ دسته اصلی
- هر دسته: عکس + نام + تعداد محصولات
- Hover: نمایش زیردسته‌ها (دسکتاپ)
- Tap: باز شدن صفحه دسته (موبایل)

### ۱.۵ محصولات منتخب

- حداکثر ۸ محصول
- الگوریتم: منتخب ادمین (نه خودکار) - چون ریهان curated است
- هر کارت: عکس + نام + قیمت + دکمه افزودن
- Hover: نمایش quick view (دسکتاپ)

### ۱.۶ داستان کوتاه ریهان

- ۲-۳ جمله
- لحن: روایت‌محور، سوم شخص
- دکمه "بیشتر بخوانید" -> صفحه درباره ما
- عکس کوچک کنار متن (اختیاری)

## ۲. کاتالوگ و جستجو

### ۲.۱ صفحه کاتالوگ

**ساختار:**
- Breadcrumb: خانه > کاتالوگ > دسته
- فیلترها (چپ/راست) + لیست محصولات

**در موبایل:**
- Breadcrumb
- Filter button + Sort button
- لیست محصولات (full width)

### ۲.۲ فیلترها

بر اساس تحقیق NN/g و Algolia:

| نوع فیلتر | نوع کنترل | رفتار |
|-----------|----------|-------|
| دسته‌بندی | چک‌باکس سلسله‌مراتبی | Multi-select |
| قیمت | Slider دو سر | Range |
| موجودی | چک‌باکس | Single |
| تأمین‌کننده | چک‌باکس | Multi-select |

**قوانین:**
- تعداد نتایج live update شود
- دکمه "پاک کردن همه" اگر فیلتری فعال است
- فیلترهای فعال به صورت tag نمایش داده شوند
- در موبایل: فیلترها در modal تمام‌صفحه

### ۲.۳ مرتب‌سازی

- پیش‌فرض (منتخب ریهان)
- جدیدترین
- قیمت: کم به زیاد
- قیمت: زیاد به کم
- پرفروش‌ترین

### ۲.۴ جستجو (Search)

بر اساس تحقیق Baymard و Algolia:

**Autocomplete:**
- فعال‌سازی: پس از ۲ کاراکتر
- Debounce: ۳۰۰ms
- حداکثر ۵ پیشنهاد
- نمایش دسته‌بندی در کنار محصول
- اگر نتیجه نداشت: "هیچ محصولی یافت نشد. پیشنهادات: ..."

**صفحه نتایج جستجو:**
- مشابه صفحه کاتالوگ
- عنوان: "نتایج جستجو برای: [عبارت]"
- اگر نتیجه نداشت: empty state با پیشنهادات

### ۲.۵ کارت محصول (در کاتالوگ)

**اجزا:**
- عکس محصول
- Badge جدید/تخفیف
- نام محصول
- داستان کوتاه (۱ خط)
- ⭐ ۴.۸ (۲۳ نظر)
- ۲۵۰,۰۰۰ تومان
- [افزودن به سبد]
- [♡ علاقه‌مندی]

**قوانین:**
- Hover: zoom کوچک عکس + نمایش quick view
- موجودی: اگر = ۰، دکمه غیرفعال + "ناموجود"
- Lazy loading عکس‌ها
- Aspect ratio: ۴:۳

## ۳. صفحه محصول (Product Page)

### ۳.۱ گالری عکس

بر اساس تحقیق Baymard:

| ویژگی | جزئیات |
|-------|--------|
| عکس اصلی | ۶۰۰px دسکتاپ، ۴۰۰px موبایل |
| فرمت | WebP + fallback JPG |
| Zoom دسکتاپ | کلیک -> modal با zoom ۲x |
| Zoom موبایل | Pinch + double-tap |
| Thumbnails | حداکثر ۶، زیر Hero |
| Swipe موبایل | چپ/راست |
| Badge جدید | اگر < ۷ روز: "جدید" |

### ۳.۲ اطلاعات محصول

| عنصر | جزئیات |
|------|--------|
| نام | H1، وزیرمتن Bold، ۲۸px |
| قیمت | سبز، ۳۲px، Bold |
| قیمت قبلی | خط‌خورده، خاکستری، ۲۰px |
| موجودی | رنگ‌بندی |
| واحد | کوچک، خاکستری |
| تأمین‌کننده | "محصول: [نام]" با لینک |

### ۳.۳ Low-Stock Urgency

**قوانین (Vision Guard اصل ۲):**
- فقط اگر واقعاً ≤ ۵
- نمایش: "⚠️ فقط ۳ عدد باقی مانده!"
- به‌روزرسانی live هر ۳۰ ثانیه
- هرگز عدد ساختگی نیست

### ۳.۴ انتخاب تعداد و افزودن

**ساختار:**
[-]  [ ۲ ]  [+]    [🛒 افزودن به سفارش]

**رفتار:**
- دکمه `-`: غیرفعال اگر = ۱
- دکمه `+`: غیرفعال اگر = موجودی + tooltip
- Input وسط: قابل تایپ مستقیم
- دکمه افزودن: ۶۰٪ عرض، سبز، ۵۶px
- پس از کلیک: loading ۵۰۰ms + mini cart popup

### ۳.۵ دکمه Wishlist

- ♡ خالی: در wishlist نیست
- ❤️ پر: در wishlist است
- Toggle + toast notification

### ۳.۶ Trust Checklist (D-048)

**۵ ستون:**

| ستون | محتوا |
|------|-------|
| داستان مبدأ | "از [محل] می‌آید..." |
| شفافیت | "قیمت شامل ارسال" |
| تماس | ☎️ شماره |
| نظرات | ⭐ امتیاز |
| حضور فیزیکی | 📍 تبریز |

### ۳.۷ بخش‌های زیر

- **داستان محصول:** ۲-۴ جمله واقعی
- **مشخصات فنی:** جدول
- **نظرات:** میانگین + لیست + فرم نظر
- **محصولات مرتبط:** حداکثر ۴

## ۴. سبد خرید (Cart)

### ۴.۱ Mini Cart Popup

**رفتار:**
- Slide-in از راست (RTL)
- عرض: ۴۰۰px دسکتاپ، ۱۰۰٪ موبایل
- محتوا: عکس کوچک + نام + قیمت + تعداد
- جمع کل پایین
- دکمه‌ها: "مشاهده سبد" + "ادامه خرید"
- Auto-dismiss: ۵ ثانیه

### ۴.۲ صفحه سبد

**رفتار:**
- تغییر تعداد: آنی + debounce ۳۰۰ms
- حذف: 🗑️ + تأیید (toast "حذف شد" با undo)
- سبد خالی: empty state با "مشاهده محصولات"

### ۴.۳ Cross-sell

**قوانین:**
- حداکثر ۳ محصول
- الگوریتم: مرتبط یا پرفروش
- عنوان: "شاید این‌ها هم دوست داشته باشید"
- فقط اگر واقعاً مرتبط باشد

## ۵. فرم سفارش (Checkout)

### ۵.۱ Progress Indicator

**قوانین:**
- فعلی: دایره سبز پر
- قبلی: تیک + لینک بازگشت
- بعدی: دایره خاکستری
- خط: سبز/خاکستری

### ۵.۲ Guest Checkout (اولویت)

**قانون Baymard:**
- دکمه "ادامه به‌عنوان مهمان" **بزرگ‌تر** از ورود
- متن: "بدون نیاز به ساخت حساب"
- بعد از خرید: پیشنهاد حساب (اختیاری)

### ۵.۳ مراحل فرم

**مرحله ۱: موبایل**
- Input شماره موبایل
- OTP: ۶ باکس، auto-fill، تایمر ۹۰s
- اگر device شناخته: skip + "خوش آمدید [نام]"

**مرحله ۲: آدرس**
- فیلدها: نام، نام خانوادگی، آدرس، شهر، استان، کد پستی
- اعتبارسنجی live با پیام فارسی
- ذخیره خودکار پیش‌نویس

**مرحله ۳: ارسال**
- ۳ گزینه: پست / تیپاکس / باربری
- نمایش هزینه هر کدام
- زمان تخمینی تحویل

**مرحله ۴: پرداخت**
- کارت‌به‌کارت (MVP)
- نمایش شماره کارت + نام صاحب
- دکمه آپلود رسید
- Trust signals: آیکون قفل، "پرداخت امن"

**مرحله ۵: تأیید**
- خلاصه کامل سفارش
- تیک "قوانین را می‌پذیرم" (اجباری)
- دکمه "ثبت نهایی سفارش"

### ۵.۴ Auto-save

- هر تغییر -> localStorage
- Toast فقط بار اول: "اطلاعات ذخیره شد"
- اگر برگشت: auto-restore

### ۵.۵ صفحه تأیید

- "سفارش شما ثبت شد! 🎉"
- شماره سفارش
- خلاصه سفارش
- دکمه "پیگیری سفارش"
- شماره پشتیبانی
- پیشنهاد: "ایجاد حساب برای پیگیری آسان‌تر"

## ۶. احراز هویت

### ۶.۱ ورود/ثبت‌نام (Passwordless)

**فرم ورود:**
- عنوان: ورود / ثبت‌نام
- Input شماره موبایل
- دکمه "ارسال کد تأیید"
- یا ادامه به‌عنوان مهمان

**صفحه OTP:**
- عنوان: کد ۶ رقمی را وارد کنید
- ۶ باکس OTP
- تایمر: ۰۱:۲۳
- دکمه "ارسال مجدد کد"
- لینک تماس در صورت مشکل

**قوانین:**
- Auto-fill از SMS (در موبایل)
- Paste: پذیرش کد کپی شده
- تایمر ۹۰s
- حداکثر ۳ تلاش -> OTP جدید
- محدودیت: ۳ OTP در ۱۰ دقیقه

### ۶.۲ Device Remembering

- پس از ورود موفق: "این دستگاه را به خاطر بسپار؟"
- پیش‌فرض: بله
- اعتبار: ۳۰ روز
- مدیریت از حساب کاربری

## ۷. حساب کاربری

### ۷.۱ داشبورد

- سلام [نام]!
- آخرین سفارش (کارت کوچک)
- آمار: تعداد سفارش‌ها، مبلغ کل
- دسترسی سریع: سفارش‌ها، علاقه‌مندی‌ها، آدرس‌ها، دستگاه‌ها، تنظیمات

### ۷.۲ لیست سفارش‌ها

- شماره سفارش + تاریخ
- تعداد محصول + مبلغ کل
- وضعیت
- دکمه‌ها: مشاهده جزئیات، پیگیری

### ۷.۳ علاقه‌مندی‌ها

- Grid از کارت‌های محصول
- دکمه "افزودن به سبد" مستقیم
- دکمه "حذف از علاقه‌مندی"

### ۷.۴ آدرس‌ها

- لیست آدرس‌های ذخیره شده
- دکمه افزودن جدید
- انتخاب آدرس پیش‌فرض
- ویرایش/حذف

### ۷.۵ دستگاه‌ها

- لیست دستگاه‌های شناخته شده
- نمایش: نوع دستگاه، آخرین استفاده، IP
- دکمه "خروج از این دستگاه"

## ۸. پیگیری سفارش

### ۸.۱ صفحه پیگیری

بر اساس تحقیق Baymard و NN/g:

**ساختار:**
- شماره سفارش
- Timeline عمودی با مراحل
- خلاصه سفارش
- آدرس تحویل
- کد رهگیری (قابل کپی) + لینک پست
- شماره پشتیبانی

**قوانین:**
- Timeline عمودی (بهترین برای موبایل)
- مرحله فعلی highlighted
- تاریخ شمسی + ساعت
- کد رهگیری قابل کپی
- لینک مستقیم به سایت پست/تیپاکس

### ۸.۲ ورود به پیگیری

**دو راه:**
1. **با حساب:** مستقیم از داشبورد
2. **بدون حساب:** فرم موبایل + شماره سفارش

## ۹. پنل ادمین

### ۹.۱ داشبورد

**قوانین:**
- حداکثر ۵-۶ کارت در صفحه اول
- اطلاعات حیاتی در بالا-راست (RTL)
- Clarity wins over cleverness

**کارت‌های اصلی:**
- سفارش‌های جدید
- درآمد امروز
- محصولات با موجودی کم
- سرنخ‌های جدید
- نظرات بدون پاسخ

### ۹.۲ مدیریت محصولات

**لیست:**
- جدول با sortable columns
- جستجو در نام
- فیلتر بر اساس دسته و وضعیت
- Bulk actions

**فرم افزودن:**
- تب‌بندی: اطلاعات، عکس‌ها، دسته‌بندی، پیشرفته
- Validation live
- پیش‌نمایش قبل از انتشار
- Draft mode

### ۹.۳ مدیریت سفارش‌ها

**لیست:**
- جدول با فیلتر وضعیت
- جستجو در شماره و نام مشتری
- Bulk actions

**صفحه جزئیات:**
- اطلاعات مشتری
- آیتم‌های سفارش
- Timeline تغییرات
- دکمه‌های عملیاتی
- آپلود کد رهگیری
- یادداشت داخلی

### ۹.۴ تا ۹.۸

- مدیریت نظرات
- مدیریت سرنخ‌ها
- گزارش مالی
- مدیریت کاربران خانواده
- لاگ فعالیت‌ها

### ۱۳.۴ Modal و Dialog

| نوع | استفاده | دکمه‌ها |
|-----|---------|---------|
| اطلاعات | پیام ساده | [باشه] |
| تأیید | قبل از عمل حساس | [انصراف] [تأیید] |
| فرم | ورود سریع | [انصراف] [ثبت] |

**قوانین:**
- Backdrop: تیره با blur
- Close: دکمه X، Esc، کلیک بیرون
- Focus trap
- Animation: fade-in ۲۰۰ms

### ۱۳.۵ Forms

**قوانین عمومی:**
- Label در بالا (نه داخل input)
- Placeholder کمکی (نه جایگزین label)
- Error: زیر فیلد، قرمز، با آیکون
- Success: زیر فیلد، سبز
- Required: ستاره قرمز
- Help text: زیر label، خاکستری کوچک

### ۱۳.۶ Buttons

| نوع | استفاده | رنگ |
|-----|---------|-----|
| Primary | عمل اصلی | سبز |
| Secondary | عمل ثانویه | خاکستری |
| Tertiary | عمل کم‌اهمیت | بدون پس‌زمینه |
| Danger | حذف | قرمز |
| Disabled | غیرفعال | خاکستری روشن |

**حالت‌ها:**
- Default
- Hover: کمی تیره‌تر
- Active: بیشتر تیره
- Disabled: خاکستری + cursor not-allowed
- Loading: spinner + "در حال..."
