## ۱. مقدمه

- شفافیت در هر گام
- بازیابی آسان

## ۲. مسیرهای مشتری

### C1: خرید مشتری آشنا (دایره اول و دوم)

**پرسونا:** P1 (مریم)، P2 (علی) | **اولویت:** Must Have | **زمان:** ۳-۵ دقیقه

    ▶ ورود به سایت (لینک پیامک / تلگرام / معرفی شفاهی)
    │
    ├─ صفحه اصلی: بنر + محصولات منتخب + داستان کوتاه ریهان
    │
    ├─ انتخاب محصول → صفحه جزئیات
    │  ├─ عکس‌ها (گالری) + داستان محصول
    │  ├─ قیمت (تومان) + موجودی
    │  └─ دکمه «افزودن به سفارش»
    │
    ├─ سبد سفارش: لیست + تغییر تعداد + جمع کل
    │  └─ دکمه «ادامه و ثبت سفارش»
    │
    ├─ فرم سفارش (چندمرحله‌ای)
    │  ├─ ۱: موبایل + OTP (یا تشخیص دستگاه به‌خاطر سپرده‌شده)
    │  │  ⚠ شماره نامعتبر → پیام راهنما
    │  │  ◇ کاربر مهمان؟ → بدون ساخت حساب ادامه دهد
    │  ├─ ۲: نام، آدرس، کد پستی ⚠ فیلد خالی
    │  ├─ ۳: روش ارسال (پست / تیپاکس / باربری)
    │  ├─ ۴: پرداخت (کارت‌به‌کارت) → نمایش شماره کارت
    │  └─ ۵: تأیید نهایی + ثبت
    │
    ├─ صفحه تأیید: شماره سفارش + شماره کارت + آپلود رسید
    │
    └─ ■ پیام: «سفارش ثبت شد. پس از تأیید اطلاع‌رسانی می‌شود.»

---

### C2: خرید مشتری غریبه (دایره سوم)

**پرسونا:** P3 (زهرا) | **اولویت:** Must Have (سال دوم) | **زمان:** ۵-۸ دقیقه

    ▶ ورود از جستجوی گوگل / اینستاگرام
    │
    ├─ صفحه فرود: محصول + نشان‌های اعتماد
    │
    ├─ ◇ نیاز به اعتمادسازی؟
    │  ├─ بله → درباره ریهان / نظرات / سیاست مرجوعی → ⟲ بازگشت
    │  └─ خیر → مستقیم به محصول
    │
    ├─ انتخاب محصول + فرم سفارش (مشابه C1)
    │  ⚠ تفاوت: تأکید بر آدرس فیزیکی و شماره تماس
    │  ◇ مهمان؟ → خرید بدون حساب فعال است
    │
    └─ ■ تأیید + لینک پیگیری + شماره پشتیبانی

---

### C3: ثبت سرنخ (Lead)

**پرسونا:** P8 (حسن) | **اولویت:** Must Have | **زمان:** ۱-۲ دقیقه

    ▶ بازدید بدون قصد خرید فوری
    │
    ├─ ◇ محصول موجود نیست؟
    │  ├─ بله → فرم سرنخ:
    │  │  ├─ نام (اختیاری) + موبایل (اجباری)
    │  │  ├─ محصول مورد نظر (اختیاری)
    │  │  └─ دکمه «اطلاع بدهید»
    │  └─ خیر → ادامه بازدید
    │
    └─ ■ پیام: «ثبت شد. به‌محض موجود شدن اطلاع می‌دهیم.»

---

### C4: پیگیری سفارش

**پرسونا:** همه مشتریان | **اولویت:** Must Have | **زمان:** ۳۰ ثانیه

    ▶ ورود به /track
    │
    ├─ ◇ وارد شده؟
    │  ├─ بله → لیست سفارش‌های اخیر
    │  └─ خیر → فرم: موبایل + شماره سفارش
    │
    ├─ جزئیات: وضعیت + خط زمانی شمسی + کد رهگیری
    │
    └─ ■ پایان

---

## ۳. مسیرهای ادمین

### A1: ورود به پنل خانواده

**پرسونا:** P4، P5 | **اولویت:** Must Have | **زمان:** ۳۰ ثانیه

    ▶ ورود به /admin
    ├─ ◇ جلسه فعال؟ بله → داشبورد | خیر → فرم ورود
    │  ⚠ ۵ بار اشتباه → قفل ۱۵ دقیقه
    └─ ■ داشبورد + ثبت لاگ ورود

---

### A2: داشبورد ادمین

**پرسونا:** P4، P5 | **اولویت:** Must Have

    ▶ /admin/dashboard
    ├─ خلاصه: سفارش جدید / درآمد / در انتظار / سرنخ
    ├─ نمودار فروش (۷ روز / ۳۰ روز / ۱۲ ماه)
    ├─ هشدارها: موجودی کم / بدون رسید / نظر بدون پاسخ
    └─ ■ کلیک روی هر بخش → صفحه مربوطه

---

### A3: افزودن محصول

**پرسونا:** P4 | **اولویت:** Must Have | **زمان:** ۵-۱۰ دقیقه

    ▶ «افزودن محصول» در /admin/products
    ├─ فرم: نام + دسته + تأمین‌کننده + قیمت + موجودی
    ├─ توضیحات کوتاه (اجباری) + داستان (اختیاری)
    ├─ عکس‌ها (۱ تا ۶) ⚠ فرمت/حجم نامعتبر
    ├─ وضعیت: فعال / غیرفعال / پیش‌نویس
    ├─ پیش‌نمایش → ◇ تأیید؟
    └─ ■ ثبت + پیام موفقیت + لاگ

---

### A4: تأیید سفارش

**پرسونا:** P4، P5 | **اولویت:** Must Have | **زمان:** ۲-۳ دقیقه

    ▶ «سفارش‌ها» → لیست با فیلتر وضعیت
    ├─ کلیک → جزئیات: مشتری + محصولات + عکس رسید
    ├─ ◇ رسید معتبر؟
    │  ├─ بله → تأیید → پیامک → لاگ
    │  └─ خیر → رد + دلیل → پیامک → لاگ
    ├─ پس از تأیید: ثبت کد رهگیری → «ارسال‌شده»
    └─ ■ پس از تحویل: «تحویل‌شده»

---

### A5: تأیید نظر

**پرسونا:** P4، P5 | **اولویت:** Must Have | **زمان:** ۱ دقیقه

    ▶ «نظرات» → لیست (در انتظار / تأیید / رد)
    ├─ کلیک → نام + محصول + متن + امتیاز
    ├─ ◇ تأیید / رد / پاسخ ادمین
    └─ ■ لاگ + بازگشت

---

### A6: گزارش مالی

**پرسونا:** P4 | **اولویت:** Must Have | **زمان:** ۲ دقیقه

    ▶ «مالی» در منوی ادمین
    ├─ درآمد کل + تعداد + میانگین + نمودار
    ├─ فیلتر: امروز / هفته / ماه / بازه دلخواه
    ├─ جدول تراکنش‌ها + خروجی اکسل (Should Have)
    └─ ■ حساب تأمین‌کنندگان + تاریخچه تسویه

---

### A7: مدیریت ماژول‌ها (Feature Flags)

**پرسونا:** P4 | **اولویت:** Must Have | **زمان:** ۱ دقیقه

    ▶ «ماژول‌ها» در منوی ادمین
    ├─ لیست ۱۴ ماژول: نام | توضیح | وضعیت
    ├─ ◇ تغییر وضعیت → تأیید «مطمئنید؟»
    │  ⚠ غیرفعال‌سازی سفارش → هشدار جدی
    └─ ■ اعمال فوری + لاگ

---

## ۴. مسیرهای تأمین‌کننده

### S1: ورود تأمین‌کننده

**پرسونا:** P6 (مولا) | **اولویت:** Must Have | **زمان:** ۳۰ ثانیه

    ▶ ورود به /supplier
    ├─ فرم: موبایل + رمز ⚠ فقط با تأیید ادمین
    └─ ■ داشبورد تأمین‌کننده

---

### S2: ثبت کد رهگیری + حساب ماهانه

**پرسونا:** P6 | **اولویت:** Must Have | **زمان:** ۲ دقیقه

    ▶ داشبورد تأمین‌کننده
    ├─ لیست سفارش‌های مرتبط
    ├─ ثبت کد رهگیری → تأیید
    ├─ حساب ماهانه: تعداد + مبلغ + سهم + تسویه‌ها
    └─ ■ پایان

---

## ۵. مسیرهای خطا و بازیابی

### E1: خطاهای عمومی

    ⚠ ۴۰۴ → پیام دوستانه + پیشنهاد صفحات + دکمه خانه
    ⚠ ۵۰۰ → «مشکلی پیش آمد» + تلاش مجدد + شماره پشتیبانی
    ⚠ قطع اینترنت → ذخیره خودکار فرم + بازیابی پس از اتصال

### E2: بازیابی دسترسی (دستگاه جدید / جلسه منقضی)

    ▶ ورود از دستگاه جدید یا پس از ۳۰ روز
    │
    ├─ مرحله ۱: ورود شماره موبایل
    │  └─ اعتبارسنجی زنده (۱۱ رقم، ۰۹)
    │
    ├─ مرحله ۲: OTP (Kavenegar Verify)
    │  ├─ ۶ رقم — Auto-fill — تایمر ۹۰ ثانیه
    │  ├─ حداکثر ۳ تلاش → OTP جدید
    │  └─ ⚠ شماره ثبت‌نشده → ثبت‌نام خودکار
    │
    ├─ مرحله ۳: ورود موفق
    │  ├─ ◇ ثبت دستگاه جدید؟ → بله → ۳۰ روز بدون OTP
    │  └─ لاگ: دستگاه جدید + زمان + IP
    │
    └─ ■ ورود موفق — دستگاه به‌خاطر سپرده شد

    نکته: «فراموشی رمز» معنی ندارد (رمز اجباری نیست)
    اگر کاربر رمز اختیاری تعریف کرده و فراموش کرده:
    OTP → ورود → تغییر رمز در تنظیمات حساب
