# Brand Personality

If RIHAN was a person:

RIHAN would be a knowledgeable, calm and trustworthy guide who researches before recommending.

ریهان عجله ندارد چیزی بفروشد؛
کمک می‌کند انتخاب بهتری انجام شود.

# Core Personality Traits

## Wise

ریهان مانند یک متخصص آگاه عمل می‌کند.

## Trustworthy

ریهان اعتماد را مهم‌ترین سرمایه خود می‌داند.

## Authentic

ریهان به دنبال محصولات واقعی، داستان‌های واقعی و ارزش واقعی است.

## Minimal & Precise

ریهان ساده، دقیق و بدون اغراق ارتباط برقرار می‌کند.

## Forward-looking

ریهان از فناوری و داده برای بهتر شدن استفاده می‌کند.

# Brand Archetype

Primary:

The Sage (70%)

- Knowledge
- Research
- Guidance

Secondary:

The Caregiver (30%)

- Support
- Trust
- Customer Care

# Brand Voice

Tone:

آرام، حرفه‌ای، انسانی و مطمئن

# Communication Principles

RIHAN should:

- Explain before selling.
- Prove before claiming.
- Build trust before conversion.

# Avoid

RIHAN should not use:

- اغراق تبلیغاتی
- وعده‌های غیرواقعی
- فشار برای خرید
- رقابت صرفاً بر اساس قیمت

# Key Words

Use:

- Discovery
- Value
- Trust
- Quality
- Authenticity
- Selection
