# RIHAN Visual Identity Brief

Version:
1.0

Date:
2026-07-31

# Visual Identity Goal

هویت بصری ریهان باید در اولین برخورد این پیام را منتقل کند:

"یک مرجع قابل اعتماد برای کشف و انتخاب محصولات ارزشمند."

# Design Philosophy

Premium Minimal

+

Smart Modern

+

Warm Authentic

# Core Visual Concept

Balance between:

1. Discover
2. Curate
3. Trust

# Logo Direction

The logo should communicate:

- Discovery of hidden value
- Careful selection
- Reliability

Preferred structure:

Wordmark + Symbol

Primary focus:

RIHAN

# Logo Requirements

The logo must be:

- Simple
- Memorable
- Scalable
- Timeless
- Suitable for digital platforms

# Avoid

The logo should not:

- Look like a traditional store
- Use direct product symbols
- Depend on temporary design trends
- Feel cheap or promotional

# Color Direction

Primary:

Deep Forest Green

Meaning:

- Trust
- Authenticity
- Depth

Secondary:

Warm Gold

Meaning:

- Value
- Premium selection

Neutral:

Warm White

Meaning:

- Simplicity
- Clarity

# Visual Feeling

The audience should feel:

"This brand helps me make better choices."

# Future Design Principle

Every visual element must support:

Discover
+
Curate
+
Trust
