## ۱. مقدمه

این سند ساختار اطلاعاتی پلتفرم ریهان را تعریف می‌کند: نقشه سایت، سیستم ناوبری، ساختار URL (سئو محور)، ساختار صفحه محصول بلوک‌محور، و قوانین برند مستقل.

### اصول

- سادگی: حداکثر ۳ سطح عمق
- دسترسی: هر صفحه حداکثر ۳ کلیک از خانه
- موبایل-اول: منوها برای لمس بهینه شوند
- مقیاس‌پذیری: ساختار بدون تغییر، ظرفیت رشد داشته باشد

## ۳. سیستم ناوبری

### ۳.۱ نوار بالایی (Header) — همه صفحات عمومی

    [لوگو ریهان] [کاتالوگ ▼] [درباره ما] [تماس] [جستجو 🔍] [حساب 👤] [سبد 🛒]

- لوگو: کلیک → خانه
- کاتالوگ: منوی کشویی با دسته‌های اصلی
- جستجو: باز شدن فیلد جستجو
- حساب: ورود / حساب کاربری
- سبد: تعداد آیتم‌ها + لینک سبد

### ۳.۲ منوی کاتالوگ (کشویی)

    ├── خشکبار
    │   ├── گردو
    │   ├── بادام
    │   └── کشمش
    ├── لباس
    │   ├── مردانه
    │   └── زنانه
    ├── لوازم منزل
    └── [سایر دسته‌ها — پویا از دیتابیس]

### ۳.۳ فوتر (Footer)

    ستون ۱: درباره ریهان (خلاصه ۲ خطی + لینک درباره ما)
    ستون ۲: دسترسی سریع (کاتالوگ / پیگیری / تماس)
    ستون ۳: اطلاعات (شماره تماس / آدرس / ساعات پاسخگویی)
    پایین: کپی‌رایت + سیاست مرجوعی

### ۳.۴ منوی کناری ادمین

    داشبورد | محصولات | دسته‌بندی | سفارش‌ها | نظرات
    سرنخ‌ها | مالی | ماژول‌ها | کاربران | تنظیمات | لاگ‌ها | خروج

### ۳.۵ منوی کناری تأمین‌کننده

    داشبورد | سفارش‌ها | ثبت رهگیری | حساب ماهانه | خروج

## ۴. ساختار URL

### ۴.۱ الگوها

| صفحه | الگو | مثال |
|------|------|------|
| خانه | / | / |
| کاتالوگ | /catalog | /catalog |
| دسته اصلی | /catalog/[category] | /catalog/dried-fruit |
| زیردسته | /catalog/[category]/[sub] | /catalog/dried-fruit/walnut |
| محصول | /product/[slug] | /product/horand-walnut-500g |
| سیاست مرجوعی | /about/return-policy | /about/return-policy |
| سبد | /cart | /cart |
| پیگیری | /track | /track |
| حساب | /account/[section] | /account/orders |
| ادمین | /admin/[section] | /admin/products |
| تأمین‌کننده | /supplier/[section] | /supplier/orders |

### ۴.۲ قوانین URL

- تمام حروف کوچک (lowercase)
- جداکننده کلمات: خط تیره (-)
- بدون کاراکتر فارسی در URL (slug انگلیسی)
- حداکثر ۳ سطح عمق
- بدون trailing slash (اسلش انتهایی حذف شود)
- Slug محصول: نام + وزن/اندازه (مثال: horand-walnut-500g)
- Slug دسته: ترجمه انگلیسی کوتاه (مثال: dried-fruit)
- ID عددی فقط در پنل ادمین (نه بخش عمومی)
- ریدایرکت 301 برای URLهای تغییرکرده

### ۴.۳ Slug محصولات — قواعد ساخت

فرمول: [مبدأ]-[محصول]-[وزن/واحد]

مثال‌ها:
- horand-walnut-500g
- horand-almond-1kg
- tabriz-raisin-250g
- horand-dried-apricot-400g

قواعد:
- حداکثر ۶۰ کاراکتر
- فقط حروف انگلیسی، اعداد، خط تیره
- بدون حرف اضافه (a, the, of)
- واحد به انگلیسی: g, kg, pcs, pack
- در صورت تکراری: افزودن عدد (horand-walnut-500g-2)

## ۴.۵ دسته‌بندی محصولات (نهایی — تأییدشده)

| # | دسته | Slug | زیردسته‌های اولیه |
|---|------|------|-------------------|
| ۱ | خشکبار و آجیل | dried-nuts | گردو، بادام، فندق، پسته، کشمش |
| ۲ | چای و نوشیدنی | tea-drinks | چای سیاه، چای سبز، دمنوش |
| ۳ | لباس و پوشاک | clothing | لباس محلی، شال، روسری |
| ۴ | لوازم منزل | home-goods | صنایع‌دستی، ظروف، تزئینی |
| ۵ | محصولات فصلی | seasonal | عید نوروز، یلدا، رمضان |
| ۶ | مواد غذایی | food | عسل، مربا، ترشی، سماق، رب |

### قوانین دسته‌بندی

- هر محصول دقیقاً **یک** دسته اصلی دارد
- زیردسته‌ها اختیاری هستند (می‌توانند خالی باشند)
- Slug دسته: انگلیسی، lowercase، خط‌تیره
- URL: /product/[slug] (مطابق نقشه سایت بخش ۴.۱)
- مدیریت: ادمین می‌تواند دسته/زیردسته اضافه یا غیرفعال کند
- دسته غیرفعال: محصولاتش از کاتالوگ حذف نمی‌شوند، فقط فیلتر حذف می‌شود

## ۸. ساختارهای جدید بر اساس D-079

> ⚠️ این بخش‌ها در تاریخ ۲۰۲۶-۰۸-۱۲ بر اساس تصمیم D-079 اضافه شده‌اند.

### ۸.۱ ساختار صفحه محصول بلوک‌محور

صفحه محصول در ریهان یک ساختار ثابت ندارد. ادمین با استفاده از ۱۲ نوع بلوک، روایت کاملی برای هر محصول می‌سازد.

**ساختار بلوک‌ها:**

| بلوک | توضیح | فیلدها |
|------|--------|--------|
| text | متن آزاد با Rich Text | content, alignment |
| heading | عنوان (H2/H3/H4) | text, level |
| image | عکس با alt و caption | image, alt_text, caption, width |
| gallery | گالری عکس | images[], columns (2/3/4) |
| video | ویدیو (آپلود یا لینک) | video_file, video_url, poster, caption |
| link | لینک | text, url, target |
| quote | نقل قول | quote, author |
| table | جدول | rows[], header_row |
| spacer | فاصله‌گذار | height (small/medium/large) |
| cta | دکمه اقدام | text, action |
| trust_badges | نشانه‌های اعتماد | badges[] |
| related_products | محصولات مرتبط | products[], max_count |

**ترتیب بلوک‌ها:**
- ادمین با drag & drop ترتیب را تنظیم می‌کند
- هر بلوک می‌تواند فعال/غیرفعال شود
- پیش‌نمایش قبل از انتشار

### ۸.۲ ساختار صفحه «درباره برند» (داستان برند، نه شخصی)

صفحه درباره ریهان فقط داستان برند را روایت می‌کند. هیچ اشاره‌ای به بنیان‌گذار نیست.

**ساختار صفحه درباره:**

| بخش | محتوا | قوانین |
|------|--------|--------|
| Hero | شعار برند + عکس برند | بدون عکس شخصی |
| مأموریت | مأموریت برند ریهان | بدون نام شخصی |
| فلسفه انتخاب | فرآیند انتخاب محصولات | بدون داستان شخصی |
| تاریخچه برند | داستان ریهان (نه بنیان‌گذار) | بدون عکس/نام شخصی |
| اصول بنیادین | اصول ۱۰گانه | بدون ارجاع شخصی |
| تعهد به مشتری | کرامت مشتری | بدون ارجاع شخصی |
| فوتر | نام برند + لینک‌ها + تماس | بدون نام شخصی |

### ۸.۳ سئو URLها

**الگوی URL برای محصولات (سئو محور):**

| الگو | مثال | توضیح |
|------|-------|--------|
| /product/{slug} | /product/somagh-horand | کلمه کلیدی در URL |
| /category/{slug} | /category/spices | دسته‌بندی با کلمه کلیدی |

**قوانین Slug:**
- کوچک (lowercase)
- بدون فاصله (با خط تیره -)
- شامل کلمه کلیدی (مثلاً somagh-horand نه product-123)
- بدون کاراکترهای فارسی در URL (ترجمه یا فینگلیش)

**فیلدهای سئو برای هر محصول:**
- seo_title: عنوان سئو (حداکثر ۶۰ کاراکتر)
- seo_description: توضیح سئو (حداکثر ۱۶۰ کاراکتر)
- seo_keywords: کلمات کلیدی (اختیاری)

### ۸.۴ ساختار پنل ادمین با ویرایشگر بلوک

**منوی اصلی پنل ادمین (خانواده):**

| منو | زیرمنوها |
|------|----------|
| داشبورد | خلاصه روزانه، نمودار فروش، هشدارها |
| محصولات | لیست، افزودن، ویرایش با بلوک، پیش‌نمایش |
| سفارش‌ها | لیست، تأیید، رد، کد رهگیری |
| نظرات | تأیید، رد، پاسخ |
| محتوا | صفحه اصلی، بنرها، درباره برند |
| سئو | تنظیمات سئو، sitemap، meta tags |
| گزارش‌ها | مالی، آماری، موجودی |
| تنظیمات | رنگ، فونت، شماره کارت، تماس |

**ویرایشگر بلوک‌محور:**
- drag & drop برای ترتیب بلوک‌ها
- پیش‌نمایش زنده (Live Preview)
- ذخیره خودکار draft
- فعال/غیرفعال کردن بلوک‌ها

### ۸.۵ قوانین برند مستقل در معماری اطلاعات

**قوانین سخت‌گیرانه:**

| قانون | توضیح |
|-------|--------|
| بدون نام بنیان‌گذار | هیچ اشاره‌ای به «عبدالحسین فهیمی» در صفحات عمومی |
| بدون عکس بنیان‌گذار | هیچ عکس شخصی بنیان‌گذار در صفحات عمومی |
| بدون داستان شخصی | صفحه درباره فقط داستان برند است |
| فوتر عمومی | فقط نام برند «ریهان» + لینک‌ها + تماس |
| پنل ادمین | می‌تواند نام ادمین‌ها را ببیند، اما سایت عمومی نه |

**تست خودکار (CI/CD):**
- اسکن تمام فایل‌های قالب و محتوا
- لیست کلمات ممنوعه: «عبدالحسین فهیمی»، «فهیمی»، «بنیان‌گذار»، «صاحب سایت»
- در صورت تشخیص، deploy رد می‌شود

### ۸.۶ سئو در Breadcrumbs

**الگوی Breadcrumbs برای صفحه محصول:**

خانه > دسته‌بندی > نام محصول

**مثال:**

خانه > ادویه‌جات > سماق هوراند

**قوانین:**
- هر سطح لینک دارد (به‌جز سطح آخر)
- Schema.org BreadcrumbList برای سئو
- در موبایل: خلاصه‌شده با «...»
