# D-092: بازطراحی پوسته ادمین ریحان + کنترل محتوای سایت از پنل (SiteSettings)

**تاریخ:** ۱۴۰۵/۰۶/۰۱ (۲۰۲۶-۰۸-۲۳)
**وضعیت:** Approved ✅ (اجرا شده روی پروداکشن — کامیت `c72fd8b`)
**انطباق:** D-042 (هویت بصری)، D-079، D-091، CENTRAL-STORY.md

## مشکل:

پنل ادمین پیش‌فرض Django بدون شخصی‌سازی بود:
- کارت‌های رنگی داشبورد کنتراست پایین داشتند و متن‌ها ناخوانا بودند
- هیچ سایدبار ناوبری وجود نداشت
- محتوای صفحه اصلی (تیتر هیرو، نقل‌قول، فوتر، اطلاعات تماس) هاردکد در قالب‌ها بود و هر تغییر نیازمند دستکاری کد و دیپلوی بود

## تصمیمات:

| # | تصمیم | جزئیات |
|---|-------|--------|
| ۱ | پوسته برند اختصاصی ادمین | Override متغیرهای CSS خود Django (`--primary`, `--body-bg`, ...) به‌جای بازنویسی کل استایل‌ها. فایل: `src/core/static/admin/css/rihan_admin.css` |
| ۲ | سایدبار دسته‌بندی‌شده | Template tag سفارشی `rihan_sidebar` در `modules/catalog/templatetags/admin_sidebar.py` — گروه‌بندی مدل‌ها با آیکون، هایلایت لینک فعال، دکمه شناور موبایل. گروه‌ها در dict `GROUPS` قابل ویرایش‌اند؛ مدل ثبت‌نشده در گروه‌ها خودکار زیر «سایر» می‌آید |
| ۳ | داشبورد خوانا | کارت‌های سفید با accent بالا، عدد تیره درشت، لیبل خاکستری تیره — قالب: `src/templates/admin/index.html` |
| ۴ | مدل Singleton تنظیمات سایت | `SiteSettings` در `modules/pages/models.py` — همیشه فقط pk=1 (متد `load()`). کنترل: نام برند، بج/تیتر/زیرتیتر/نقل‌قول هیرو، عنوان بخش برگزیده‌ها، نوار اطلاعیه (فعال/غیرفعال + متن)، تلفن/ایمیل/آدرس/ساعات کاری، اینستاگرام/تلگرام/واتساپ، متن‌های فوتر |
| ۵ | Context Processor سراسری | `pages.context_processors.site_settings` → متغیر `site_settings` در **همه** قالب‌ها (از جمله ادمین) در دسترس است |

## نکات فنی برای توسعه‌دهنده بعدی:

- تغییر قالب‌ها → `docker restart rihan_web` لازم است (کش قالب)
- تغییر static → `collectstatic` لازم است (whitenoise)
- برای افزودن مدل جدید به سایدبار: فقط ورودی در `GROUPS` اضافه کنید؛ URL خودکار از registry ساخته می‌شود
- لینک مستقیم فرم تنظیمات: `/admin/pages/sitesettings/1/change/`
- ⚠️ اگر روزی SiteSettings حذف/تغییر نام یافت، context processor را هم به‌روز کنید وگرنه کل سایت ۵۰۰ می‌دهد
