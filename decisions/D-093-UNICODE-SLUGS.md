# D-093: اسلاگ یونیکد مجاز است — قانون دائمی URL Converter

**تاریخ:** ۱۴۰۵/۰۶/۰۱ (۲۰۲۶-۰۸-۲۳)
**وضعیت:** Approved ✅ (اجرا شده — کامیت `ab1aa11`)
**شدت:** 🔴 باگ پروداکشن (۵۰۰ کل سایت)

## حادثه:

محصولی با نام کاملاً فارسی «سماق قرمز هوراند» ثبت شد. slugify آن را به
`سماق-قرمز-هوراند` تبدیل کرد. اما الگوی URL از converter پیش‌فرض `<slug:slug>`
استفاده می‌کرد که regex آن فقط `[-a-zA-Z0-9_]+` است → موقع رندر لینک محصول در
صفحه اصلی `NoReverseMatch` → **ارور ۵۰۰ در کل سایت**.

## تصمیم (قانون دائمی):

> **هر URL pattern که اسلاگ محصول/موجودیت کاربر-تعریف می‌گیرد باید `<str:...>` باشد نه `<slug:...>`.**
> نام محصولات فارسی است و باید بمانند (D-002، D-009).

## فایل‌های اصلاح‌شده:

| فایل | تغییر |
|------|-------|
| `modules/catalog/urls.py` | `products/<slug:slug>/` → `products/<str:slug>/` |
| `modules/leads/urls.py` | `register/<slug:product_slug>/` → `<str:product_slug>/` |
| `modules/reviews/urls.py` | دو مسیر submit/api → `<str:product_slug>/` |

## نکته تکمیلی:

کامنت چندخطی `{# ... #}` در قالب جنگو **پشتیبانی نمی‌شود** و عیناً در خروجی HTML
لو می‌رود (بافت در `partials/trust_badges.html` — کامیت `8e5ef15`).
قانون: برای کامنت چندخطی از `{% comment %}{% endcomment %}` استفاده شود؛
`{# #}` فقط تک‌خطی.
