# D-104 — صفحه فروش اقناعی هشت‌بخشی (Conversion Architecture)

**تاریخ:** 1405/06/03 — **وضعیت:** Accepted

## زمینه
بریف کاربر: تبدیل صفحه کاتالوگی به «صفحه فروش اختصاصی با نرخ تبدیل حداکثری» — پاسخ ۵ ثانیه اول به ۳ سوال ناخودآگاه خریدار (تحول زندگی/اعتماد/تضمین سرمایه) + حریم خصوصی + صفر اصطکاک + سبکی + اشتراک ویروسی.

## معماری ۸ بخشی (پیاده‌سازی شده)
1. **هیرو خرید سریع**: تیتر نتیجه‌محور (`result_headline`)، قیمت خط‌خورده + بج درصد تخفیف (`compare_at_price`)، دکمه «خرید سریع» (افزودن + پرش مستقیم به تسویه با `fast_buy=1`)، سه تعهد ثابت (۷ روز ضمانت/ارسال بیمه‌شده/بسته‌بندی محرمانه)
2. **فیلتر شفاف مخاطب**: دو ستون سبز/قرمز (`fit_for` / `not_fit_for`)
3. **داستان گزینش** (`curation_story`) با رندر امن mini-markup
4. **هاب اشتراک ویروسی**: شمارنده زنده (POST `products/<slug>/share/` با F()+1 بدون رفرش)، استوری اینستاگرام (کپی لینک + `instagram://story-camera` + راهنمای استیکر Link)، تلگرام/واتساپ/ایتا (لینک اشتراک)، بله (کپی+توست)، پیامک (sms: با تشخیص iOS)، X intent، Web Share API
5. **نظرات محرمانه**: فیلد `Review.display_anonymously` (پیش‌فرض True) → نمایش «خریدار تأییدشده 🔒»؛ فرم ۲ ثانیه‌ای (ستاره+متن+تیک ناشناس) با endpoint جدید `reviews:inline/<slug>/` — فقط خریدار تحویل‌شده، سفارش خودکار انتخاب، در صف تایید ادمین
6. **FAQ اختصاصی محصول**: مدل `ProductFaq` + آکاردئون بدون JS
7. **مقاله سئو/هوش مصنوعی** (`deep_dive`)
8. **نوار چسبان موبایل**: IntersectionObserver روی هیرو، نام+قیمت+خرید سریع

## زیرساخت
- **JSON-LD**: Product (قیمت ریالی IRR=×۱۰، موجودی، برند) + AggregateRating + FAQPage در `extra_head` (بلاک جدید base.html)
- **تمپلیت‌تگ** `sales_tags.py`: فیلتر `render_markup` (استفاده مجدد از pages/markup.py)
- **ادمین**: بخش «🛒 صفحه فروش اقناعی» + «🎯 فیلتر مخاطب» + «🔍 داستان گزینش و مقاله سئو» + اینلاین ProductFaq — همه محتوا بدون دستکاری قالب
- همه بخش‌ها شرطی‌اند: فیلد خالی = بخش مخفی (صفحه تمیز تا ادمین محتوا بدهد)

## ⚠️ دام مهم
در ویرایش قالب، جایگذاری CSS داخل بلاک extra_css با `</style>` اضافی باعث نشت CSS به‌صورت متن روی صفحه شد (ارتفاع صفحه ۲ برابر!) — بعد از هر تغییر قالب، تعادل `<style>`/`</style>` با شمارش چک شود.
دام دوم: scp چندفایله یک‌جا گاهی ناقص می‌شود → بعد از scp حتماً وجود فایل روی سرور grep شود.

## تست‌ها
۲۳ تست جدید (رندر بخش‌ها، JSON-LD، شمارنده، حریم خصوصی نظرات، خرید سریع، ادمین) — **مجموع ۲۳۹ تست سبز** — تست زنده روی سماق قرمز هوراند ✓
