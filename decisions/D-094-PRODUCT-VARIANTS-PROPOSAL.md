# D-094: سیستم تنوع محصول (Product Variants) — پیشنهاد

**تاریخ:** ۱۴۰۵/۰۶/۰۱ (۲۰۲۶-۰۸-۲۳)
**وضعیت:** 🟡 Proposed — در انتظار تأیید بنیان‌گذار
**اولویت:** بالا (پیش‌نیاز ورود محصولات واقعی وزنی/پوشاک)

## وضعیت فعلی (محدودیت):

مدل `Product` فقط **یک قیمت** (`base_price` → `final_price`) و **یک رکورد موجودی**
(`Inventory` با OneToOne) دارد. یعنی:

| نیاز واقعی | وضعیت فعلی |
|------------|------------|
| سماق در بسته نیم‌کیلو / یک‌کیلو با قیمت متفاوت | ❌ باید دو «محصول» جدا ثبت شود |
| لباس در سایز و رنگ‌های مختلف | ❌ پشتیبانی نمی‌شود |
| موجودی جداگانه برای هر بسته/سایز | ❌ فقط یک شمارنده کلی |

## گزینه A: بدون تغییر دیتابیس (راه‌حل موقت)

هر بسته/سایز = یک Product جداگانه («سماق ۵۰۰ گرمی»، «سماق یک‌کیلویی»).
- ✅ امروز کار می‌کند، صفر هزینه فنی
- ❌ صفحه‌های تکراری، نظرات بین بسته‌ها تقسیم می‌شود، سبد خرید شلوغ، SEO ضعیف

## گزینه B: مدل Variant (پیشنهاد اصلی)

جدول جدید `ProductVariant`:
```
ProductVariant:
    product     FK(Product, related_name='variants')
    title       CharField        ← «نیم‌کیلو» / «سایز L رنگ آبی»
    sku         SlugField?       ← اختیاری
    price       Decimal          ← قیمت نهایی این واریانت
    unit        CharField        ← کیلوگرم / عدد
    is_active   Boolean
    sort_order  Integer
Inventory → ForeignKey(product) فعلی + variant (nullable برای سازگاری)
CartItem / OrderItem → variant_id (nullable؛ null = محصول ساده قدیمی)
```

### نقاط اثرگذاری که باید همزمان تغییر کنند:

1. **مدل‌ها + migration** — catalog, order
2. **ادمین** — Inline واریانت داخل ProductAdmin + نمایش قیمت بازه‌ای در changelist
3. **صفحه محصول** — چیپ‌های انتخاب واریانت (وزن/سایز/رنگ)، به‌روزرسانی زنده قیمت و موجودی (JS سبک)
4. **سبد خرید** — کلید session باید product+variant شود
5. **CheckoutService** — رزرو موجودی از Inventory واریانت
6. **پنل تامین‌کننده** — لیست موجودی بر اساس واریانت
7. **نظرات و سرنخ‌ها** — بدون تغییر (سطح محصول می‌مانند)

### ترتیب پیشنهادی اجرا (۲ مرحله):

- **مرحله ۱:** مدل + migration + ادمین + صفحه محصول + سبد/تسویه (هسته قابل استفاده)
- **مرحله ۲:** پنل تامین‌کننده + گزارش‌ها + مرتب‌سازی واریانت‌ها

> ⚠️ تا تأیید نشود هیچ تغییری در دیتابیس اعمال نشده است.
> اگر گزینه A انتخاب شود این سند آرشیو می‌شود.
