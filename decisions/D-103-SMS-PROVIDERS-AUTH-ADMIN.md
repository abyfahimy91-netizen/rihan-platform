# D-103 — مدیریت کامل سرویس پیامک و روش‌های ورود از پنل ادمین

**تاریخ:** 1405/06/03 — **وضعیت:** Accepted

## زمینه (درخواست کاربر)
1. کلید API سرویس پیامک از پنل ادمین قابل وارد کردن باشد (نه فقط .env)
2. روش پیش‌فرض ورود (OTP یا رمز عبور) قابل انتخاب باشد
3. هر روش قابل فعال/غیرفعال شدن باشد
4. چند API قابل ثبت باشد تا در قطعی یکی، دیگری سریع فعال شود

## تصمیمات

### ۱) مدل `SmsProvider` — چند سرویس، فقط یکی فعال
- فیلدها: name، provider_type (کاوه‌نگار/قاصدک/اس‌ام‌اس آی‌آر/فراز)، api_key، otp_template، sender، is_active، priority، last_status، last_used_at
- قانون: فقط یک سرویس فعال — فعال‌کردن یکی، بقیه را خودکار غیرفعال می‌کند (در save مدل)
- **failover خودکار**: اگر سرویس فعال شکست بخورد، بقیه سرویس‌های دارای کلید به ترتیب اولویت (عدد کوچک‌تر = زودتر) امتحان می‌شوند
- نتیجه هر تلاش در last_status ثبت می‌شود تا ادمین وضعیت را ببیند
- رجیستری `PROVIDER_CLASSES` در sms_providers/__init__ — سرویس جدید فقط یک کلاس + یک خط
- سازگاری عقب: اگر هیچ رکوردی نباشد، کاوه‌نگار از متغیر محیطی (.env) خوانده می‌شود مثل قبل

### ۲) مدل `AuthSettings` — تک‌رکورد (مثل SiteSettings)
- otp_enabled / password_enabled / default_method
- otp_ttl_minutes / otp_max_attempts / show_code_on_sms_fail (نمایش اضطراری کد روی صفحه)
- clean(): هر دو روش نباید هم‌زمان خاموش شوند
- صفحه ورود تابع این تنظیمات است: تب‌ها شرطی، روش پیش‌فرض تعیین‌کننده تب اول، اگر روشی خاموش باشد POST آن هم در سرور رد می‌شود، اگر هر دو خاموش باشد صفحه «ورود موقتاً غیرفعال است»

### ۳) امنیت
- کلید API در ادمین ماسک‌شده (PasswordInput) — خالی گذاشتن = حفظ کلید قبلی
- PhoneOTP.sent_via ثبت می‌کند هر کد از کدام سرویس رفته (دیباگ قطعی‌ها)
- وقتی هیچ سرویسی در دسترس نیست و نمایش کد هم خاموش است → درخواست OTP رد می‌شود با پیام محترمانه (کد حذف می‌شود)

### ۴) ادمین
- «🔐 تنظیمات ورود و پیامک» — فرم تک‌صفحه‌ای
- «📡 سرویس‌دهنده‌های پیامک» — لیست با بج فعال/غیرفعال، اولویت قابل ویرایش درجا، اکشن «⚡ فعال‌سازی سرویس انتخاب‌شده»، وضعیت آخرین ارسال

## راهنمای اتصال کاوه‌نگار برای ادمین
۱. kavenegar.com → تنظیمات → کلید API را کپی کن
۲. پنل ادمین → سرویس‌دهنده‌های پیامک → افزودن: نوع «کاوه‌نگار»، کلید، قالب «rihan-otp» (باید در پنل کاوه‌نگار قالبی با متغیر %token ساخته شود)
۳. تیک «فعال» → ذخیره
۴. تست: یک ورود واقعی بزن؛ اگر خطا خورد، last_status همان ردیف علت را نشان می‌دهد
