# D-101 — مبلغ واریز صفحه پرداخت به ریال + ترتیب بخش‌ها مطابق اپ بانکی

**تاریخ:** 1405/06/02 — **وضعیت:** Accepted

## زمینه (گزارش کاربر — باگ بزرگ مغایرت مالی)
1. «مبلغ قابل پرداخت» و دکمه کپی آن به **تومان** بود و راهنما هم می‌گفت «مبلغ را دقیقاً به تومان واریز کنید» — در حالی که همراه بانک و اینترنت‌بانک مبلغ را **ریال** می‌پذیرند → ریسک واریز ۱۰ برابر کمتر / مغایرت حسابداری
2. ترتیب بخش‌های صفحه باید دقیقاً مثل اپ پرداخت باشد: ۱) کارت به کارت ۲) مبلغ ۳) وارد کردن ۴ رقم آخر — راهنما هم همین ترتیب

## کشف باگ خطرناک‌تر حین پیاده‌سازی
- `data-copy="{{ order.total_price }}"` مقدار **Decimal خام** را کپی می‌کرد: `2954000.00` — چسباندن این در فیلد مبلغ اپ بانکی خطا/مبلغ اشتباه می‌دهد. (فیلد total_price داری decimal_places=2 است)

## تصمیمات
- ویو (`tracking_views.py`): کانتکست جدید `amount_rial = int(total_price * 10)` (عدد صحیح تمیز برای کپی) + `amount_rial_display = money(...)`؛ صفحه موفقیت هم `amount_rial_display` گرفت
- قالب پرداخت: هیرو مبلغ → **ریال درشت** + خط کوچک «معادل X تومان» + دکمه «کپی مبلغ (ریال)»
- ترتیب جدید صفحه: بخش ۱ کارت‌های مقصد → بخش ۲ مبلغ واریز → راهنمای سه‌مرحله‌ای (۱ کارت به کارت / ۲ مبلغ ریالی / ۳ چهار رقم آخر) → بخش ۳ ثبت رسید
- صفحه موفقیت: کنار مبلغ تومانی، «(معادل X ریال)» اضافه شد
- سیستم داخلی (Payment.amount، ادمین، پیگیری) به‌همان تومان ماند — فقط نمایش واریز مشتری ریالی شد
- تست‌ها: ۲ تست جدید (ریال‌بودن کپی + ترتیب بخش‌ها و راهنما)؛ تست قدیمی عنوان بخش اول به‌روز شد؛ **۱۷۳ تست سبز**
