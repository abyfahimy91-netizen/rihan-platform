# D-100 — صفحات عمومی ادمین‌محور + صفحه سوالات متداول (رفع 404)

**تاریخ:** 1405/06/02 — **وضعیت:** Accepted

## زمینه (گزارش کاربر)
1. صفحه «سؤالات متداول» در فوتر لینک شده بود (`/faq/`) ولی صفحه وجود نداشت → 404
2. شماره تلفن واقعی در پنل ادمین وارد شده بود، اما صفحه «تماس با ما» همان شماره تست قدیمی هاردکد (`۰۹۱۲-۳۴۵-۶۷۸۹`) را نشان می‌داد — قالب اصلاً از `SiteSettings` نمی‌خواند
3. خواسته: محتوای صفحات سایت از طریق پنل ادمین و در «تنظیمات سایت» قابل ویرایش باشد
4. باگ کشف‌شده حین بررسی: لینک «پیگیری سفارش» داخل قالب تماس به `/order/tracking/` می‌رفت که وجود خارجی ندارد (مسیر درست `/order/lookup/`)

## تصمیمات

### ۱) صفحه سوالات متداول (FAQ)
- مدل جدید `FaqItem` (question / answer / sort_order / is_active) — سوال‌ها رکورد دیتابیسی‌اند، نه کد
- ویو `faq_view` + مسیر `pages:faq` روی `/faq/` — آکاردئون `<details>/<summary>` بدون جاوااسکریپت
- مایگریشن seed سه سوال پیش‌فرض (همان سه سوالی که قبلاً در قالب تماس هاردکد بود)؛ اگر ادمین قبلاً سوالی ثبت کرده باشد seed دست نمی‌زند
- ادمین: `FaqItemAdmin` با ویرایش سریع ترتیب/فعال از خود لیست

### ۲) اتصال صفحات ثابت به تنظیمات سایت
- فیلدهای جدید `SiteSettings`: `about_title`، `about_body`، `return_policy_title`، `return_policy_body`، `faq_intro`
- قالب تماس کاملاً تنظیمات‌محور شد: تلفن (لینک tel با مقدار خام + نمایش ارقام فارسی)، ایمیل، آدرس، ساعات پاسخگویی، شبکه‌های اجتماعی — کارت هر فیلد خالی مخفی می‌شود
- باکس تکراری FAQ داخل صفحه تماس حذف → کارت دعوت به صفحه `/faq/`

### ۳) موتور متن ساختارمند (`pages/markup.py`)
- کاربر غیربرنامه‌نویس است؛ HTML خام خطرناک و ناکاربرد است. یک فرمت متنی سبک تعریف شد:
  - خط خالی = پاراگراف جدید | `# متن` = تیتر | `- متن` = فهرست نقطه‌ای | `۱.` یا `1.` = فهرست شماره‌ای | `> متن` = نقل‌قول برجسته
- همه ورودی‌ها قبل از ساخت HTML escape می‌شوند — هیچ HTML خامی اجرا نمی‌شود
- پیش‌فرض فیلدها = بازنویسی دقیق محتوای فعلی قالب‌ها؛ پس هیچ محتوایی از دست نرفت

### ۴) رفع لینک‌های شکسته
- `/order/tracking/` در contact.html → `{% url 'pages:contact' %}` و لینک‌های داخلی با `{% url %}` ساخته می‌شوند

## نتایج تست زنده
- `/faq/` `/contact/` `/about/` `/return-policy/` همگی 200
- صفحه تماس: `tel:09143183790` (شماره واقعی ادمین) ✓ — شماره تست قدیمی صفر مورد ✓
- ۱۸ تست جدید (`src/modules/pages/tests/`) شامل تست موتور markup، نمایش/ترتیب/فعال‌بودن سوالات، عدم حضور شماره تست و لینک شکسته
- کل مجموعه: **۱۷۱ تست سبز**
