# D-111 — استاندارد کد رهگیری، وضعیت «در انتظار تایید»، شرکت حمل «سایر» و UX پنل تامین‌کننده

**تاریخ:** 1405/06/05 (2026-08-27) | **وضعیت:** پیاده‌سازی کامل + 314 تست سبز + تست زنده

## گزارش کاربر (۶ قلم)
1. سفارشِ رسیدآپلودکرده «در انتظار پرداخت» نشان می‌داد؛ باید «در انتظار تایید» باشد
2. رسید پرداخت در ادمین با کلیک باز نمی‌شد
3. «بدون قیمت» کنار اقلام ارسالی پنل ادمین/تامین‌کننده حذف شود
4. کد رهگیری باید استاندارد هر شرکت حمل اعتبارسنجی شود (تحقیق شد)
5. شرکت حمل «سایر» → نام شرکت/ارسال‌کننده/تلفن + نمایش به مشتری
6. کد پستی اگر الزام پست است برای مشتری اجباری شود (تحقیق شد) + لینک رهگیری در پروفایل + UX راهنمامحور پنل تامین‌کننده

## تحقیق (منابع وب — Aug 2026)
- **پست پیشتاز:** ۲۰ تا ۲۴ رقم (پورتال/سامانه‌ها) + فرمت بین‌المللی S10 مثل `RA123456789IR`
- **تیپاکس:** ۱۵ تا ۲۵ رقم؛ **چاپار:** دقیقاً ۱۴ رقم (شماره بارنامه، chaparnet/gahar)
- **کد پستی:** الزام قانونی درج کدپستی روی مرسولات پستی (خبرگزاری مهر 1399)؛ ثبت مرسوله «صرفاً با کد پستی معتبر» → ورودی مشتری اجباری شد (۱۰ رقم، ارقام فارسی نرمال می‌شود)

## پیاده‌سازی
- **Order.awaiting_review / status_display_label / status_badge_code:** رسید PENDING_REVIEW → برچسب «در انتظار تایید پرداخت» در پیگیری/پروفایل + اعلان داخلی + حذف دکمه «تکمیل پرداخت» (`can_pay` دیگر برای رسیددار True نمی‌شود)
- **fulfillment.py:** `CARRIER_CODE_RULES` + `validate_tracking_code()` + `carrier_code_hint()`؛ `mark_shipped` پارامترهای `other_carrier_*` را می‌گیرد و برای OTHER بدون کد هم کار می‌کند (شرکت/شخص/تلفن الزامی)؛ قالب پیامک `DEFAULT_CUSTOMER_SHIPPED_SMS_OTHER`
- **Shipment:** فیلدهای `other_carrier_name/person/phone` (order.0013) + پراپرتی‌های `carrier_full_label` و `other_details_text`
- **ادمین:** `PaymentInline` در صفحه سفارش با ستون «📎 مشاهده رسید»؛ `evidence_preview` لیست پرداخت‌ها هم لینک شد؛ `ShipmentAdminForm` اعتبارسنجی کد + الزامات OTHER
- **پروفایل مشتری:** کارت مرسوله per سفارش (شرکت حمل + کد LTR + دکمه «🔍 رهگیری مرسوله» با لینک مستقیم سامانه باربری یا `/order/t/`؛ جزئیات OTHER)
- **تسویه:** کد پستی الزامی (فرم + JS + address_service + گارد آدرس ذخیره‌شده بدون کدپستی)
- **پنل تامین‌کننده UX:** داشبورد «سفر ارسال ۳ قدم» + آمار کلیک‌خور + راهنمای سریع فرمت کدها؛ جزئیات مرسوله قدم‌به‌قدم (۱ اقلام → ۲ آدرس/کپی → ۳ ثبت کد) با راهنمای پویا per شرکت حمل (data-hints + JS) و فیلدهای OTHER شرطی؛ لیست با چیپ فیلتر وضعیت
- عبارت «بدون قیمت» از قالب و متن دستور ارسال حذف شد (قانون عدم افشای قیمت پابرجا — تست NotContains تومان سر جایش است)
